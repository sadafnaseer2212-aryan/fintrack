How the forecast works

  1. Your expenses are grouped into monthly totals. The current month is left out because it isn't finished.
  2. Three scikit-learn models are trained: a Baseline (average of the last 3 months), Linear Regression (long-term trend) and a Random Forest Regressor (patterns in the previous 3 months' totals).
  3. Each model is tested chronologically: for each recent month it only sees data that existed two months earlier, just like forecasting next month today. No future data is used, so there is no data leakage.
  4. Errors are measured with MAE, RMSE and MAPE, and the lowest MAE wins. If the simple baseline wins, it is used, because a complex model isn't automatically better.
  5. The winning model is retrained on all completed months to forecast next month. The RMSE gives the uncertainty band.
  6. With fewer than 9 completed months there isn't enough data to test models, so a clearly-labelled low-confidence baseline is shown instead. Below 3 months, no forecast is made.
